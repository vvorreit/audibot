Ne pas faire de git commit + push après chaque changement.
Attendre que l'utilisateur dise explicitement de committer/pusher.

**Why:** L'utilisateur préfère regrouper les commits et décider lui-même quand pusher.
**How to apply:** Faire les modifications, confirmer que ça marche, mais ne pas git add/commit/push sauf demande explicite.
