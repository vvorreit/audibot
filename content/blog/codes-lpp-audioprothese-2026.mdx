# Codes LPP audioprothèse 2026 : le référentiel à garder sous la main

Les codes LPP (Liste des Produits et Prestations), c'est la base de la facturation. Et pourtant, c'est une source régulière d'erreurs — souvent parce que les codes changent et que tout le monde n'a pas le réflexe de mettre à jour sa documentation.

Ce guide est à jour au moment de la publication. Vérifiez toujours sur le site officiel ameli.fr avant de facturer.

## Les catégories principales

### Aides auditives adultes (20 ans et plus)

**Classe I (remboursement intégral 100% Santé)**

| Type | Code LPP | Description |
|---|---|---|
| Monaural | 2185720 | Aide auditive classe I, adulte, appareillage unilatéral |
| Binaural | 2185721 | Aide auditive classe I, adulte, appareillage bilatéral |

Tarif de responsabilité 2026 : 950€ pour le monaural, 1 900€ pour le binaural (mis à jour annuellement).

**Classe II (libre, avec plafond de remboursement)**

| Type | Code LPP | Description |
|---|---|---|
| Monaural | 2185722 | Aide auditive classe II, adulte, appareillage unilatéral |
| Binaural | 2185723 | Aide auditive classe II, adulte, appareillage bilatéral |

Le remboursement classe II est plafonné à 450€ par oreille (AMO + AMC). Au-delà, reste à charge patient.

### Aides auditives enfants (moins de 20 ans)

Les codes sont différents pour les enfants, avec des tarifs de remboursement généralement plus élevés.

| Type | Code LPP |
|---|---|
| Monaural enfant | 2185730 |
| Binaural enfant | 2185731 |

*Note : pour les enfants, la prescription doit émaner d'un spécialiste ORL.*

### Accessoires et prestations associées

- **Piles** : des codes LPP spécifiques selon le type de pile, couverts trimestriellement selon les contrats
- **Entretien et réparation** : codes selon la nature de l'intervention
- **Adaptateur de bain** : pris en charge dans certains contrats

## Les confusions fréquentes

**Classe I vs Classe II.** Ce n'est pas une question de qualité ou de technologie — c'est une question de tarification. Un appareil peut être inscrit en classe I ou classe II selon son positionnement tarifaire. Vérifiez toujours la classe de l'appareil que vous facturez.

**Appareillage vs renouvellement.** Le code est le même, mais les délais de remboursement diffèrent. Un renouvellement avant le délai (4 ans pour les adultes, 2 ans pour les enfants) nécessite généralement une justification médicale.

**Appareillage unilatéral vs bilatéral.** Ne facturez pas deux fois un appareillage monaural pour obtenir l'équivalent du binaural. C'est factuellement incorrect et les portails le détectent.

## Comment rester à jour

Les codes LPP peuvent être modifiés par arrêté ministériel, souvent en début d'année.

**Sources officielles :**
- [ameli.fr/professionnels-de-sante](https://www.ameli.fr/professionnels-de-sante) — la référence
- Journal officiel pour les modifications

**Abonnements pratiques :**
- La newsletter du SYNEA (Syndicat National des Entreprises d'Audioprothèse) signale les mises à jour importantes
- Les mailings de vos portails mutuelles (Almerys, Viamedis, Wemind) alertent aussi sur les changements

## Quand un code est refusé

Si un portail refuse votre code avec une erreur "code non reconnu" ou "code non éligible" :

1. Vérifiez que vous n'avez pas fait de faute de frappe
2. Vérifiez que le code est toujours valide (ameli.fr)
3. Vérifiez que l'appareil est bien inscrit à la LPP avec ce code

En cas de doute, appelez la hotline professionnels du portail concerné. Ils ont accès aux listes à jour.
