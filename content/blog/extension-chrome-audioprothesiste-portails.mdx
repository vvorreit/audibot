# Extension Chrome pour audioprothésiste : comment ça simplifie les portails mutuelles

La première fois qu'on m'a parlé d'une extension Chrome pour remplir les portails mutuelles, j'ai été sceptique. "C'est quoi exactement ? Un truc qui clique à ma place ?"

Pas tout à fait. Voici comment ça fonctionne et pourquoi c'est différent d'un simple script.

## Le problème que ça résout

Vous avez les données de votre patient dans votre logiciel métier (Audiosoft, Noah, Sycle...). Vous devez les re-saisir dans le portail Almerys, puis dans Wemind si le conjoint est sur un autre contrat, puis dans Viamedis pour la complémentaire de l'employeur.

Le même numéro d'adhérent, le même nom, le même audiogramme de référence. Saisi trois fois. Avec le risque de faute de frappe à chaque fois.

C'est ce problème que résout une extension Chrome comme AudiBot.

## Concrètement, qu'est-ce qu'une extension Chrome fait ?

Une extension Chrome s'intègre directement dans votre navigateur. Elle "voit" la page du portail que vous avez ouverte et peut interagir avec les champs du formulaire.

Avec AudiBot, le workflow ressemble à ça :

1. Vous ouvrez le portail Almerys dans Chrome comme d'habitude
2. L'extension détecte qu'il s'agit d'Almerys
3. Vous avez déjà scanné la carte mutuelle et la prescription en début de consultation
4. Vous cliquez sur "Remplir" dans l'extension
5. Les champs se remplissent automatiquement avec les données correctes
6. Vous vérifiez visuellement (5-10 secondes) et validez

Ce que vous faites toujours : vérifier, valider, soumettre. Vous restez maître de chaque dossier.

## Ce que l'extension ne fait pas

Pour être transparent :

**Elle ne soumette pas automatiquement.** Vous devez cliquer sur "Soumettre" vous-même. C'est voulu — vous gardez le contrôle.

**Elle ne garantit pas le remboursement.** Si le contrat du patient ne couvre pas, si la prescription est expirée, si le plafond annuel est atteint, l'extension ne peut pas le savoir.

**Elle ne remplace pas votre jugement.** Si les données affichées semblent incorrectes, ne validez pas. Vérifiez à la source.

## Confidentialité et sécurité

C'est la question légitime. Où vont les données ?

Avec AudiBot : les données patient restent sur votre poste et dans votre navigateur. Rien n'est envoyé à nos serveurs. L'extension fonctionne en local, vous authentifiez vous-même sur chaque portail.

C'est une architecture "privacy by design" compatible RGPD — essentiel quand on parle de données de santé.
